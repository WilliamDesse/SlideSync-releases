# SlideSync

Diaporama photo calé sur la musique, pour macOS. Importez un dossier de photos et un morceau : SlideSync
détecte le tempo et change de photo sur les temps, en cadence lente, normale, rapide ou automatique. Vous
réglez ensuite l'ordre, les passages plus rapides, les titres et le logo, puis vous exportez en MP4 (16:9,
3:2 ou Reel 9:16). Un plugin Lightroom Classic, fourni avec l'app, garde les photos à jour après chaque
retouche.

## Télécharger

**[Télécharger la dernière version (SlideSync.dmg)](https://github.com/WilliamDesse/SlideSync-releases/releases/latest/download/SlideSync.dmg)**

Ouvrez le .dmg, glissez SlideSync dans Applications, puis lisez le « Lisez-moi » : installation du plugin
Lightroom et premier diaporama.

Toutes les versions : [Releases](https://github.com/WilliamDesse/SlideSync-releases/releases).

## Configuration requise

- macOS 14 (Sonoma) ou plus récent
- Mac Apple Silicon ou Intel
- Lightroom Classic pour le plugin (facultatif)

L'app est signée et notarisée par Apple.
